# @awarded/log4brains-web

This package provides the static site generation features of the [Log4brains](https://github.com/FreakinWard/log4brains) architecture knowledge base.
It is not meant to be used directly.

Install [the main log4brains package](https://www.npmjs.com/package/log4brains) instead:

```bash
npm install -g @awarded/log4brains
```
