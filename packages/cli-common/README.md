# @awarded/log4brains-cli-common

This package provides common features for all [Log4brains](https://github.com/FreakinWard/log4brains) CLI-based packages.
It is not meant to be used directly.

Install [the main log4brains package](https://www.npmjs.com/package/log4brains) instead:

```bash
npm install -g @awarded/log4brains
```

## Documentation

- [Log4brains README](https://github.com/FreakinWard/log4brains/blob/develop/README.md)
